# V.O.G. — Vision Official Guider

Proyecto tecnológico orientado a mejorar la movilidad de personas con discapacidad visual, mediante la integración de hardware y software. Ganador de concursos nacionales y sudamericanos de innovación con impacto social.

## Funcionalidades

- Detección de obstáculos mediante sensores ultrasónicos
- Procesamiento de señales con microcontrolador Arduino
- Alertas para el usuario según la distancia detectada
- Integración hardware-software para asistencia en tiempo real

## Tecnologías

Arduino · Sensores ultrasónicos · Programación de microcontroladores
